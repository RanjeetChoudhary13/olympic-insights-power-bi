## Power BI Setup

After downloading and extracting the dataset:

1. Open `dashboard/olympic.pbix`.
2. Select `Transform data`.
3. Open `Data source settings`.
4. Select each source and choose `Change Source`.
5. Connect each query to its corresponding CSV file.
6. Select `Close & Apply`.
7. Refresh the dashboard.

The raw data is used for educational and portfolio purposes. Dataset ownership remains with its respective source.
